Une librairie.
Toute la certification ENI SQL.

Un seul projet fil rouge, de la première table à l’examen blanc : une librairie en ligne avec clients, livres, catégories, commandes, lignes de commande et paiements. PostgreSQL sert de référence, avec les variantes MySQL et SQLite.

Comment apprendre avec ce manuel ?

Chaque chapitre suit quatre temps : Comprendre (le besoin et l’idée), Observer (la syntaxe, les schémas et les résultats), Pratiquer (exercices avec correction dépliable) et Valider (QCM justifiés). Prédisez toujours le résultat avant de l’exécuter dans votre client SQL.

Progression facultative par navigateur : activez JavaScript pour cocher les chapitres terminés.

    Scripts SQL fournis

    Le dossier sql/ contient, pour chacun des trois moteurs, quatre scripts : préparation (01_setup), schéma (02_schema), données (03_seed) et réinitialisation (04_reset). Lisez le README.md avant de les exécuter : ils suppriment des tables.
