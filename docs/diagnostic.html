Avant de commencer

Diagnostic initial

Six questions rapides, sans note, pour choisir votre point d’entrée.

Six questions pour situer votre point de départ. Elles ne sont pas notées : chaque réponse est justifiée. Si plusieurs vous échappent, commencez par le chapitre 00 ; si tout vous semble acquis, parcourez le chapitre 14 puis l’examen blanc.

Valider · question 1

Qu’est-ce que SQL ?

Voir la justification de chaque réponse
  • Incorrect — Un système de gestion de base de données : Cela, c’est le SGBD (PostgreSQL, MySQL…).
  • Bonne réponse — Un langage pour interroger et modifier des bases de données relationnelles : Structured Query Language.
  • Incorrect — Un tableur : Un tableur n’est pas un SGBD.

Valider · question 2

Dans une table, une « ligne » représente…

Voir la justification de chaque réponse
  • Bonne réponse — un élément précis (un client, un livre) : Une ligne = un enregistrement.
  • Incorrect — une caractéristique commune à tous les éléments : C’est une colonne.
  • Incorrect — une règle de validation : C’est une contrainte.

Valider · question 3

À quoi sert une clé primaire ?

Voir la justification de chaque réponse
  • Incorrect — À accélérer les calculs : Ce n’est pas son rôle premier.
  • Bonne réponse — À identifier chaque ligne de façon unique : Unique et jamais NULL.
  • Incorrect — À relier deux bases : Elle identifie, elle ne relie pas.

Valider · question 4

Que signifie NULL ?

Voir la justification de chaque réponse
  • Incorrect — Zéro : C’est une valeur.
  • Bonne réponse — Une valeur absente ou inconnue : Ce n’est ni 0 ni du texte vide.
  • Incorrect — Une erreur : Une donnée peut légitimement manquer.

Valider · question 5

Quelle requête affiche les livres à plus de 10 € ?

Voir la justification de chaque réponse
  • Bonne réponse — SELECT title FROM books WHERE unit_price > 10; : SELECT … FROM … WHERE.
  • Incorrect — SELECT title WHERE unit_price > 10 FROM books; : Ordre des clauses incorrect.
  • Incorrect — FIND books WHERE unit_price > 10; : FIND n’existe pas.

Valider · question 6

Une clé étrangère garantit que…

Voir la justification de chaque réponse
  • Incorrect — la table ne contient aucun doublon : C’est UNIQUE.
  • Bonne réponse — la valeur existe dans la table référencée : Intégrité référentielle.
  • Incorrect — la colonne n’est jamais vide : C’est NOT NULL.
