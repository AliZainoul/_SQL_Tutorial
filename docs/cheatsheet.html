Cheatsheet SQL

Chaque instruction avec son objectif, sa syntaxe, un exemple sur la librairie, ses erreurs fréquentes et sa compatibilité PostgreSQL / MySQL / SQLite.

Catégories SQL

DQL (interrogation : SELECT), DML (manipulation : INSERT, UPDATE, DELETE), DDL (définition : CREATE, ALTER, DROP), DCL (droits : GRANT, REVOKE), TCL (transactions : COMMIT, ROLLBACK). La classification varie : le référentiel ENI range SELECT parmi les instructions DML (« rechercher/lire »), d’autres sources le classent à part en DQL ; les transactions sont parfois rattachées au DML. Cette page retient DQL / DML / DDL / DCL / TCL.

Le champ « ENI » indique si la notion figure dans les critères du référentiel (C.1 à C.4), si elle est un prérequis proche ou si elle est hors référentiel. Les résultats affichés ont été obtenus en exécutant les exemples sur le jeu de référence. Sans JavaScript, tout reste visible ; les filtres apparaissent quand JavaScript est actif.

DQL · interrogation

SELECT … FROM

DQL ENI : C.1

Objectif. Lire des colonnes d’une table.

SYNTAXE
SELECT col1, col2 FROM table;

Paramètres. col : colonnes à renvoyer (* = toutes) ; table : source.

EXEMPLE
SELECT title, unit_price FROM books ORDER BY book_id LIMIT 3;

Résultat sur le jeu de référence.

titleunit_price
Les Misérables12.90
Le Rouge et le Noir9.50
Germinal8.90

Erreurs fréquentes. Utiliser * dans une application ; oublier le FROM.

  • PostgreSQL : Oui
  • MySQL : Oui
  • SQLite : Oui

Différences. Identique sur les 3 moteurs. SELECT est parfois classé DML, parfois DQL.

Référence : chapitre 06.

WHERE

DQL ENI : C.1

Objectif. Filtrer les lignes selon une condition.

SYNTAXE
SELECT … FROM t WHERE condition;

Paramètres. condition : comparaison, AND/OR/NOT, IN, BETWEEN, LIKE, IS NULL.

EXEMPLE
SELECT title FROM books WHERE unit_price > 10 ORDER BY book_id;

Résultat sur le jeu de référence.

title
Les Misérables
Vingt mille lieues sous les mers
La Guerre des Gaules
Histoire de la Révolution française
Python pour les curieux
SQL pas à pas

Erreurs fréquentes. = NULL au lieu de IS NULL ; texte sans apostrophes ; agrégat dans WHERE.

  • PostgreSQL : Oui
  • MySQL : Oui
  • SQLite : Oui

Référence : chapitre 06.

SYNTAXE

Paramètres. ASC par défaut ; plusieurs colonnes possibles.

EXEMPLE

FETCH FIRST

DQL ENI : Hors référentiel

Objectif. Forme standard SQL de limitation.

SYNTAXE
… ORDER BY … OFFSET k ROWS FETCH FIRST n ROWS ONLY;

Paramètres. Équivalent de LIMIT.

EXEMPLE
SELECT title FROM books ORDER BY book_id OFFSET 3 ROWS FETCH FIRST 3 ROWS ONLY;

Erreurs fréquentes. L’utiliser sur MySQL ou SQLite.

  • PostgreSQL : Oui
  • MySQL : Non
  • SQLite : Non

Différences. PostgreSQL seulement parmi les trois ; utiliser LIMIT ailleurs.

UPSERT

DML ENI : Hors référentiel

Objectif. Insérer ou mettre à jour si la clé existe.

SYNTAXE
INSERT … ON CONFLICT (col) DO UPDATE SET … | … ON DUPLICATE KEY UPDATE …

Paramètres. Syntaxe propre à chaque moteur.

EXEMPLE

Erreurs fréquentes. Syntaxe d’un moteur copiée sur un autre.

  • PostgreSQL : Oui
  • MySQL : Oui
  • SQLite : Oui

Différences. PostgreSQL et SQLite : ON CONFLICT ; MySQL : ON DUPLICATE KEY UPDATE.
